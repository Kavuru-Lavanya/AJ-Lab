Step 1: Database Setup
Let’s assume your database is MySQL and you have a table:

sql
Copy
Edit
CREATE TABLE employee (
    emp_id INT PRIMARY KEY,
    emp_name VARCHAR(50),
    salary DECIMAL(10, 2)
);


Step 2: Create Stored Procedures
(a) Procedure to Insert One Record
sql
Copy
Edit
DELIMITER $$

CREATE PROCEDURE insert_employee(
    IN p_emp_id INT,
    IN p_emp_name VARCHAR(50),
    IN p_salary DECIMAL(10,2)
)
BEGIN
    INSERT INTO employee (emp_id, emp_name, salary)
    VALUES (p_emp_id, p_emp_name, p_salary);
END$$

DELIMITER ;
(b) Procedure to Retrieve Salary by Employee ID
sql
Copy
Edit
DELIMITER $$

CREATE PROCEDURE get_salary_by_id(
    IN p_emp_id INT,
    OUT p_salary DECIMAL(10,2)
)
BEGIN
    SELECT salary INTO p_salary
    FROM employee
WHERE emp_id = p_emp_id;
END$$

DELIMITER ;

Step 3: Java JDBC Application
Make sure you have MySQL Connector/J JAR in your classpath.
Example filename: JDBCStoredProcDemo.java

java
Copy
Edit
import java.sql.*;

public class JDBCStoredProcDemo {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/Studentdb";
        String user = "lavanya"; 
        String password = "lavanya29";

        try (Connection conn = DriverManager.getConnection(url, user, password)) {
            System.out.println("Database connected.");

            // 1. Call insert_employee procedure
            CallableStatement insertStmt = conn.prepareCall("{call insert_employee(?, ?, ?)}");
            insertStmt.setInt(1, 101);
            insertStmt.setString(2, "John Doe"); 
            insertStmt.setDouble(3, 55000.00);
            insertStmt.execute();
            System.out.println("Record inserted successfully.");

            // 2. Call get_salary_by_id procedure
            CallableStatement getSalaryStmt = conn.prepareCall("{call get_salary_by_id(?, ?)}");
            getSalaryStmt.setInt(1, 101); 
            getSalaryStmt.registerOutParameter(2, Types.DECIMAL); 
            getSalaryStmt.execute();

            double salary = getSalaryStmt.getDouble(2);
            System.out.println("Salary for Employee ID 101 is: " + salary);

            // Close resources
            insertStmt.close();
            getSalaryStmt.close();

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}

Step 4: How It Works
insert_employee inserts a record into the table.

get_salary_by_id takes emp_id as input and gives salary as output.

JDBC code:

Uses CallableStatement to call stored procedures.

Sends parameters using setInt(), setString(), setDouble().

Retrieves output parameters using registerOutParameter() and getDouble().


Output:


Database connected.
Record inserted successfully.
Salary for Employee ID 101 is: 55000.0
